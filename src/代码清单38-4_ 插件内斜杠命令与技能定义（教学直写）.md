## /subscribe-app <租户> <应用ClientID> [到期时间]

技能：subscribe-app-flow

### 步骤

1. 核对租户与应用
   - 租户在租户列表在册；应用 Client ID 在平台应用列表在册。
   - 任一不在册：停在第一步，先补事实再动手，不带着存疑往下走。
2. 提交订阅
   - Client ID 必填。
   - 到期时间缺省视为永久。
3. 回读确认
   - 订阅列表当即多出该应用一行。
   - 回读不见该行判失败，回报缺哪一环，不靠感觉宣布成功。

### 收尾

报告三要素——租户、应用、到期时间，附订阅列表回读行。

### 边界

- 只做订阅与回读，不碰角色菜单授权（授权走第 37 章的配角色流程）。
- 移除订阅不在本插件范围。
