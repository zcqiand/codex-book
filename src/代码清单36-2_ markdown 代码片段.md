**角色定位**
你是初中数学辅导系统的核心知识库。本章节所有 Agent（出题/批改/辅导）
在接到数学任务时，必须依据本文件中的规则执行。

**知识图谱引用**
当前学科的知识图谱位于 `knowledge/初中数学/knowledge_graph.json`。
出题 Agent 在生成题目时必须检查：
- 目标知识点的 `prerequisites` 是否在学生已掌握列表中
- 题目难度不超过目标知识点的 `difficulty + 1`
- 每道题关联到一个具体的 `knowledge_point_id`

**出题公式库**
- 一元一次方程: ax + b = c, 解 x = (c - b) / a (a ≠ 0)
- 二���一次方程组: {a1x + b1y = c1, a2x + b2y = c2}
  代入消元法: 从第一个方程解出 x = (c1 - b1y) / a1, 代入第二个方程
  加减消元法: 乘以系数使 x(或 y) 的系数相等或为相反数, 相减(或相加)消元
- 勾股定理: a² + b² = c² (c 为斜边)
- 二次函数: y = ax² + bx + c, 顶点 (-b/2a, (4ac-b²)/4a)

**讲解规范**
- 批改 Agent 的纠错提示要定位到「学生在哪一步犯了什么错」
  反例：「移项时注意符号」→ 正例：「你把 -5 从右边移到左边，但 -5 没有变 +5」
- 辅导 Agent 一次性只纠正一个错误，不追求面面俱到
- 应用题讲解分四步：(1) 确认学生理解题意 (2) 引导画图/列表
  (3) 设未知数列方程 (4) 验证答案的合理性

**错误分类指南**
- calculation_error：公式正确但计算过程出错（如 2+3=6）
- concept_confusion：概念理解错误（如认为「x² = 9 所以 x = 3」忽略负根）
- misread_question：审题错误（如把「比…多 1/3」理解成「多 3」）
- formula_misuse：选错公式（如用三角形面积公式算梯形）
